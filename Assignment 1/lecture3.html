Lecture 3: HTML Forms and Media

Interactive user inputs, validation attributes, and media controls

Summary

This lecture explores interactive web forms, input controls, HTTP submission methods (GET and POST), HTML5 input validation, tabular data structure, and embedding audio/video media.

Topics Covered:

  • HTML Forms & Controls
    • Form Architecture
      • Form tag with action and method attributes
      • Accessible label association with form inputs
      • Fieldsets and legends for grouped fields
    • Input Types & Buttons
      • Text, password, email, and number inputs
      • Radio buttons, checkboxes, and select dropdowns
      • Submit buttons and form validation attributes
    • Tables & Multimedia
      • Tabular layout: table, tr, th, and td tags
      • Audio and video embedding controls

Example Code:

<form action="#" method="POST">
  <label for="st-name">Student Name:</label><br>
  <input type="text" id="st-name" placeholder="Enter Full Name" required><br><br>
  <input type="submit" value="Register Now">
</form>
