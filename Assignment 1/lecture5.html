Lecture 5: CSS Selectors

Targeting precision, element/class/ID selectors, combinators, and specificity

Summary

This lecture details how CSS selectors bind styles to elements in the DOM tree, covering basic selectors (element, class, ID), combinators (child, descendant, adjacent), pseudo-classes (:hover, :focus), and the cascade specificity calculation rules.

Topics Covered:

  • CSS Selectors
    • Basic Selectors
      • Element/Type selector (p, h1, div)
      • Class selectors (.highlight) and ID selectors (#main)
      • Universal selector (*) and grouping comma syntax
    • Combinators
      • Descendant selector (div p)
      • Direct child selector (ul > li)
      • Adjacent sibling (+) and general sibling (~)
    • Pseudo-Classes & Specificity
      • Interactive states: :hover, :focus, and :active
      • Structural selectors: :first-child and :nth-child
      • Specificity hierarchy and cascade resolution

Example Code:

<style>
  .btn-hover {
    background-color: #2458a6;
    color: white;
    padding: 7px 16px;
    border: none;
    border-radius: 4px;
    cursor: pointer;
  }
  .btn-hover:hover {
    background-color: #143566;
  }
</style>
<button class="btn-hover">Hover Over Me!</button>

Output:

(Move cursor over the button to see :hover state)
