Lecture 7: Responsive Web Design

Mobile-first development, viewport meta tag, and media queries

Summary

This lecture details techniques for building responsive web designs that adapt seamlessly across devices, focusing on the viewport meta tag, relative CSS units (rem, em, %, vw), fluid layouts, and CSS media queries (@media).

Topics Covered:

  • Responsive Web Design
    • Viewport Meta Tag
      • Configuring width=device-width and initial-scale=1.0
      • Device pixel ratio and mobile viewport scaling
    • Fluid Measurement Units
      • Relative units: rem, em, percentages (%), vw, vh
      • Responsive images using max-width: 100% and auto height
    • CSS Media Queries
      • Syntax: @media screen and (max-width: 768px)
      • Mobile-first breakpoints for phones, tablets, and desktops

Example Code:

<style>
  .responsive-banner {
    padding: 12px;
    background-color: #e0f2fe;
    color: #0369a1;
    text-align: center;
  }
  @media (max-width: 600px) {
    .responsive-banner {
      background-color: #fef3c7;
      color: #92400e;
    }
  }
</style>
<div class="responsive-banner">Fluid Responsive Container</div>

Output:

Fluid Responsive Container (Adapts dynamically to viewport)
