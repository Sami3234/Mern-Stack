Lecture 2: HTML Basics

HTML document structure, fundamental tags, headings, and lists

Summary

This lecture introduces HyperText Markup Language (HTML), covering basic document skeleton, tags, element attributes, heading hierarchy, paragraphs, hyperlinks, lists, and the distinction between block-level and inline elements.

Topics Covered:

  • HTML Document Structure
    • Document Skeleton
      • DOCTYPE declaration and html root tag
      • Head section, meta tags, and document title
      • Body container for visible web content
    • Text & Structural Tags
      • Headings hierarchy (<h1> to <h6>)
      • Paragraphs (<p>) and Line Breaks (<br>)
      • Text emphasis (<strong>, <em>)
    • Hyperlinks & Lists
      • Anchor tags (<a> with href attribute
      • Unordered lists (<ul> with bullet points
      • Ordered lists (<ol> with numbered items

Example Code:

<h2>HTML Fundamentals</h2>
<p>HTML creates the <strong>structural skeleton</strong> of web pages.</p>
<ul>
  <li>Headings and Paragraphs</li>
  <li>Links and Lists</li>
</ul>

Output:

HTML Fundamentals

HTML creates the structural skeleton of web pages.

  • Headings and Paragraphs
  • Links and Lists
