Lecture 4: Introduction to CSS

Styling web documents, syntax rules, inclusion methods, and color systems

Summary

This lecture introduces Cascading Style Sheets (CSS), isolating visual presentation from structural HTML. It explains CSS syntax (selectors, properties, values), the three inclusion methods (inline, internal, external), and foundational font and color properties.

Topics Covered:

  • Introduction to CSS
    • CSS Fundamentals
      • Separation of presentation from content
      • CSS rule syntax: selector { property: value; }
      • Declaration blocks and property values
    • Inclusion Methods
      • Inline styles using style attribute
      • Internal styling within style element
      • External stylesheets via link tag
    • Colors & Typography
      • Color names, HEX, RGB, and HSL formats
      • Font families, font sizes, and font weights

Example Code:

<style>
  .styled-box {
    background-color: #e0f2fe;
    color: #0369a1;
    border: 1px solid #7dd3fc;
    padding: 10px;
    border-radius: 4px;
    font-weight: bold;
  }
</style>
<div class="styled-box">This element is styled using CSS!</div>

Output:

This element is styled using CSS!
