Lecture 8: Introduction to JavaScript

Client-side interactivity, variables, event handling, and DOM manipulation

Summary

This lecture introduces JavaScript, the programming language that enables dynamic interactivity in web applications. It covers script inclusion, variables, data types, functions, event handling, and modifying Document Object Model (DOM) elements.

Topics Covered:

  • Introduction to JavaScript
    • JavaScript Fundamentals
      • Including scripts via <script> tag
      • Variable declarations: let, const, and var
      • Data types: String, Number, Boolean, Object
    • DOM Manipulation
      • Accessing elements using document.getElementById()
      • Modifying text content with innerText and innerHTML
      • Dynamic CSS style manipulation via JavaScript
    • Events & Functions
      • Handling user events: onclick, oninput, onsubmit
      • Function declarations and interactive handlers

Example Code:

<button onclick="updateText()">Click Me</button>
<p id="demo-msg">Initial text before interaction.</p>

<script>
  function updateText() {
    document.getElementById("demo-msg").innerText = "Text dynamically updated by JavaScript!";
    document.getElementById("demo-msg").style.color = "#16a34a";
  }
</script>

Output:

Initial text before interaction.
