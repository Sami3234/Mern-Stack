Lecture 6: CSS Box Model & Layout

Margin, border, padding, content area, box-sizing, and display modes

Summary

This lecture explores the fundamental CSS Box Model governing all HTML block rendering: content area, padding, border, and margin. It explains the critical box-sizing: border-box property, element display types, and positioning basics.

Topics Covered:

  • CSS Box Model & Layout
    • Box Model Components
      • Content Area: width and height dimensions
      • Padding: inner space between content and border
      • Border: perimeter line surrounding padding
      • Margin: outer spacing separating neighboring elements
    • Box-Sizing Property
      • box-sizing: content-box vs. border-box
      • Preventing layout overflow with border-box
    • Display & Flow
      • Block, inline, and inline-block display modes
      • CSS positioning: static, relative, absolute, fixed

Example Code:

<style>
  .box-container {
    box-sizing: border-box;
    margin: 10px 0;
    padding: 12px;
    border: 2px dashed #2458a6;
    background-color: #fdfaf3;
  }
</style>
<div class="box-container">
  <strong>Content Area</strong> inside Padding, Border & Margin
</div>

Output:

Content Area inside Padding, Border & Margin
